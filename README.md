# AI/ML 7-Day Revision

A hands-on 7-day Artificial Intelligence and Machine Learning revision sprint focused on strengthening fundamentals through coding and practical projects.

The objective of this repository is not to collect notes or copy solutions. The focus is to understand the concepts, write code independently, debug problems and explain the complete workflow clearly in interviews.

---

## Goal

The main goals of this revision sprint are:

* Strengthen Python fundamentals
* Revise NumPy and Pandas
* Understand statistics used in Machine Learning
* Revise important Machine Learning algorithms
* Practise data cleaning and EDA
* Build regression and classification models
* Understand unsupervised learning
* Revise NLP fundamentals
* Build an end-to-end Machine Learning project
* Improve problem-solving and debugging skills
* Become confident explaining projects in interviews

# Learning Approach

For this revision sprint, I am following a learning-by-doing approach.

For each day:

1. Understand the concept.
2. Write the code independently.
3. Run the program.
4. Identify and fix errors.
5. Understand why the code works.
6. Explain the approach.
7. Connect the concept to Machine Learning.
8. Prepare interview explanations.
9. Document the work.

The goal is understanding rather than simply completing code.
